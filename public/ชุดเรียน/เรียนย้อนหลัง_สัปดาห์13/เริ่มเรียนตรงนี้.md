# W13 — Data Storytelling และการนำเสนอเพื่อตัดสินใจ

## เป้าหมาย
- เชื่อมคำถาม ผลวิเคราะห์ และข้อเสนอแนะโดยใช้หลักฐานได้
- คำนวณยอดขายและสัดส่วนเมนูที่มียอดขายสูงที่สุดได้
- แยกข้อเท็จจริง สมมติฐาน และข้อจำกัดสำหรับการนำเสนอได้

## เตรียมไฟล์
- drinks_shop.csv

อัปโหลดไฟล์ผ่าน Files ใน Colab ผู้สอนและผู้เรียนเขียนคำสั่งพร้อมกันทีละขั้น ใช้หนึ่งเซลล์ต่อขั้น และตรวจผลก่อนทำต่อ

## โครงสร้างข้อมูล
- drinks_shop.csv: 40 แถว 5 คอลัมน์ — date, day, menu, cups, price

ทำตามสไลด์ทีละขั้น ใช้ Notebook ฝึกพิมพ์และเทียบ Notebook ตัวอย่าง เมื่อ Runtime เริ่มใหม่ให้อัปโหลดข้อมูลและเรียกใช้เซลล์ก่อนหน้าทั้งหมด
