# คู่มือผู้เรียน — การวิเคราะห์และนำเสนอข้อมูล

เรียน 15 สัปดาห์ วันจันทร์ 3 ชั่วโมง และวันพฤหัสบดี 2 ชั่วโมง

## การเรียนพร้อมผู้สอน
1. เลือกสัปดาห์และวันจากสารบัญ เปิดชุดเรียนและดาวน์โหลดไฟล์ข้อมูลกับ Notebook ที่ระบุ
2. เปิด Notebook ใน Google Colab ผ่าน File → Upload notebook
3. อัปโหลดไฟล์ข้อมูลผ่านแถบ Files → Upload ตรวจชื่อไฟล์ให้ตรงกับคำสั่ง
4. อ่านคำอธิบายและเขียนคำสั่งพร้อมผู้สอนทีละรายการลงเซลล์ว่าง
5. กด Shift + Enter แล้วเทียบผลกับหน้าถัดไป อธิบายผลก่อนเริ่มขั้นใหม่
6. บันทึก Notebook และใช้ Notebook ตัวอย่างพร้อมผลลัพธ์ทบทวนเมื่อเรียนย้อนหลัง

หาก Runtime เริ่มใหม่ ให้อัปโหลดข้อมูลอีกครั้งและเรียกใช้เซลล์จากด้านบน ก่อนต่อคำสั่งวันพฤหัสบดี

## เครื่องมือ
ใช้ pandas เตรียมและวิเคราะห์ข้อมูล เพิ่ม Plotly ในสัปดาห์ 11–12 สำหรับกราฟและ Dashboard โดยสอนคำสั่งที่เพิ่มทีละขั้น

ข้อมูลฝึกเป็นข้อมูลสมมติ ตรวจความหมายและหน่วยจากพจนานุกรมข้อมูล โดย price ใน drinks_shop.csv หมายถึงยอดเงินรวมรายการ ไม่ใช่ราคาต่อแก้ว

## การประเมิน
การปฏิบัติในคาบใช้ Notebook และคำอธิบายผลเป็นหลักฐานตามเกณฑ์ประจำสัปดาห์ สัปดาห์ 8 สอบกลางภาค สัปดาห์ 14 นำเสนอโครงงาน และสัปดาห์ 15 สอบปลายภาค ใช้คำชี้แจงของผู้สอนและไม่คิดคะแนนซ้ำ

เว็บแสดงสื่อและผลอ้างอิง การเรียกใช้คำสั่งจริงทำใน Colab ตามลำดับขั้น
