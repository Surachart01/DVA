# W11 — Visualization สร้างภาพข้อมูล

## จุดประสงค์การเรียนรู้
- สร้างกราฟแท่งเปรียบเทียบยอดขายจากข้อมูลสรุปได้
- สร้างกราฟเส้นตามวันที่ที่มีข้อมูลและกำหนดชื่อแกนได้
- สร้างกราฟกระจายเพื่อพิจารณาจำนวนแก้วและยอดเงินต่อรายการได้
- ส่งออกกราฟแบบโต้ตอบเป็นไฟล์ HTML เพื่อเปิดภายหลังได้

## การเตรียมไฟล์ข้อมูล
- drinks_shop.csv

อัปโหลดไฟล์ข้อมูลผ่านเมนู Files ในโปรแกรม Google Colab แล้วพิมพ์คำสั่งและรันผลลัพธ์ตามลำดับทีละขั้นตอน

## โครงสร้างชุดข้อมูล
- ไฟล์ drinks_shop.csv: จำนวน 40 แถว 5 คอลัมน์ ได้แก่ date, day, menu, cups, price

ทำตามสไลด์ทีละขั้น ใช้ Notebook ฝึกพิมพ์และเทียบ Notebook ตัวอย่าง เมื่อ Runtime เริ่มใหม่ให้อัปโหลดข้อมูลและเรียกใช้เซลล์ก่อนหน้าทั้งหมด
