# สื่อการสอน 31901-2012 การวิเคราะห์และนำเสนอข้อมูล

15 สัปดาห์ 495 สไลด์ ตามแนวทางการสอนของ https://nos-gamma.vercel.app: สารบัญหน่วย เป้าหมาย แนวคิด แผนภาพ คำสั่งทีละส่วน ตัวอย่าง แล็บ และบันทึกครูรายสไลด์

## เปิดใช้

```sh
npm install
npm run dev
```

เปิด http://localhost:3000 เลือกสัปดาห์จากสารบัญ ใช้ลูกศรซ้าย/ขวาเปลี่ยนสไลด์ F เต็มจอ หรือเลือกหน้าจากเมนูด้านล่าง บันทึกครูเปิด/ซ่อนได้

## ชุดประกอบ

ไฟล์ใช้งานอยู่ใน ../ชุดพร้อมสอน_31901-2012 มี Word สี่ไฟล์ Notebook ผู้เรียน/ครูอย่างละ 15 แผนและใบงานละเอียด ชุดข้อมูล และตารางคะแนน/เวลาเรียน

หน้าเว็บมีโหมดสไลด์ ใบงาน และชุดเรียน พร้อมตัวอย่างโต้ตอบ Pipeline คุณภาพข้อมูล Join Moving Average การเลือกกราฟ และ Dashboard HTML จาก Notebook จริง

## แหล่งเนื้อหา

- src/teachingDeck.js: สไลด์หลักและบันทึกครูรายสไลด์
- src/labsData.js: ใบงาน เป้าหมายและรูบริกที่สัมพันธ์กับแผน
- src/courseResources.js: รายการไฟล์ผู้เรียน
- public/ชุดเรียน: เฉพาะไฟล์เผยแพร่ให้ผู้เรียน

src/slidesData.js และ teacherScripts.js เก็บชุดข้อมูลสื่อที่จัดเรียงไว้ก่อนปรับเครื่องเล่นเป็นแนว NOS ส่วนแผนรายสัปดาห์เดิมอยู่ในโฟลเดอร์รายวิชาและสำเนาพร้อมสอน

```sh
npm run build
npm run preview
```

โฮสต์เฉพาะ dist ห้ามโฮสต์โฟลเดอร์สำหรับครู คะแนนหรือเฉลยสอบ โค้ด Python รันบน Colab เว็บไม่ประเมินผลรายวิชาอัตโนมัติ
